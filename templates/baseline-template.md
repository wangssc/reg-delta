# 基线录入模板

> 用途：为规则文件建立可检索的条款索引，供比对时逐条拆四要素。

## 规则名称

（填写规则名称，须为用户提供的名称）

## 版本信息

- 版本号：（如 v1）
- 生效日期：（材料给出则填；未给出则填「待核」）
- 来源：（用户提供 / 用户粘贴内容）

## 条款索引

| 条款号 | 正文（摘要或原文） | 主体 | 行为方向 | 数值·阈值 | 时限·生效条件 |
|--------|--------------------|------|----------|-----------|----------------|
| §x.y   |                    |      |          |           |                |

> 每行一条规则，拆出四要素。要素无法从正文确定时填「待核」。
