# 差分报告模板（三段式）

> 用途：填写后即为交付报告。固定三段，不增不减。

## 报告头

- 规则名称：
- 基线版本：vN　→　新版版本：vN+1
- 比对日期：
- 缺失版本说明：（无则写「无」；有则写「中间缺失 vX，本期变化可能不完整」）

---

## 第一段：一句话结论

（一句话概括本期变了什么；若来源不可核实，只写「本期未取得可核实来源，不出报告。」并结束）

---

## 第二段：影响清单

| # | 条款位置 | 生效日期 | 变化类型 | 四要素变化点 | 对应资产（文件 + 锚点） | 建议动作 |
|---|----------|----------|----------|--------------|--------------------------|----------|
| 1 |          |          |          |              |                          |          |

（未命中任何资产的条目，在「对应资产」列写「无对应资产」）

---

## 第三段：本期过滤掉的变化

（逐条列出不报为变化的项，并说明理由）

- 纯措辞：……（四要素全同，不报）
- 数字写法变化：……（数值未变，不报）
- 位置调整：……（正文一字未改，不报为删除+新增）
- 待人工确认：……（原文未变、口径存疑，不计入结论）

---

## 待生效分区（如有）

（生效日期晚于当前日期的变化，单独列于此，不混入第二段）
