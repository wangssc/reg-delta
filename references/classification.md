# 分类判据：义务四要素比对

## 四要素

每条规则拆为四要素，逐项比对：

| 要素 | 含义 | 判定问题 |
|------|------|----------|
| 主体 | 谁承担义务 | 「谁」变了吗？ |
| 行为方向 | 必须 / 禁止 | 「应当」变「不得」了吗？ |
| 数值·阈值 | 数量、金额、门槛 | 数值或门槛变了吗？ |
| 时限·生效条件 | 何时生效、以何为条件 | 期限或触发条件变了吗？ |

## 判定规则

1. **四要素全同** → 不是变化。即使句子措辞、语序、数字写法不同。
2. **至少一个要素变** → 变化。类型按变动要素命名：
   - 主体变化
   - 行为方向变化
   - 阈值变化（数值·阈值要素变）
   - 时限变化（时限·生效条件要素中的期限变）
   - 生效条件变化（时限·生效条件要素中的触发条件变）
3. **整条正文一字未改、仅编号移动** → 不是变化，最多单列「位置调整」。判定依据是正文全等，不是编号是否连续。
4. **原文未变、怀疑官方口径变（解释变化）** → 归「待人工确认」，不计入结论。仅当用户额外提供官方解读材料时才启用。

## 过滤清单（不报为变化的项）

- 纯措辞调整：改说法、改语序、改句式，四要素全同。
- 数字写法变化但数值未变：如「三十日」→「30 日」、「一百万元」→「100 万元」。
- 位置调整：正文一字未改，仅编号位置移动。
- 待人工确认：原文未变但口径存疑（解释变化）。

以上每一项都要在报告第三段「本期过滤掉的变化」中单列说明。

## 为什么四要素比「新增/修订/废止/解释变化」更少误报

旧分类把「条款」和「义务」混在一个维度。一条条款里可能承载多个义务；旧分类会因其中一个义务变了而把整条判为「修订」，或者更糟——把整条视为一个变化单元，丢失「到底哪个义务变了」的定位。

反例：某条款同时规定「应当报备（义务 A）且应当在三十日内完成（义务 B）」。新版只把三十日改为十五日，义务 A 未动。旧分类会整条报「修订」，用户看不出是「报备」变了还是「期限」变了。四要素比对则精确落到义务 B 的「时限」要素，输出「§x 时限变化：30 日 → 15 日」，义务 A 不动。

代价：需要为每条规则做要素拆分，前置录入成本略高。换取的是「变化定位到要素级、措辞差异自动过滤」。
